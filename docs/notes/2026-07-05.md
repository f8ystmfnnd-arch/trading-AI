\# 2026-07-05 개발 메모



\## 작업 주제



BTC Market Regime \& Risk Guard AI 프로젝트에 기술지표 feature 실험과 Streamlit 기반 대시보드 초안을 추가했다.



오늘의 핵심은 기존의 실험 스크립트 중심 구조에서 벗어나, 실제로 시장 판세를 눈으로 확인할 수 있는 대시보드 형태로 프로젝트를 발전시킨 것이다.



\## 주요 진행 내용



\### 1. 기술지표 feature 추가



`create\\\_features\\\_with\\\_indicators.py`를 새로 추가했다.



기존 15분봉 multi-timeframe feature에 아래 기술지표 기반 feature를 추가했다.



```text

Bollinger Band 20

ATR 14

MA slope

RSI slope

```



추가된 주요 feature:



```text

bb\\\_middle\\\_20

bb\\\_upper\\\_20

bb\\\_lower\\\_20

bb\\\_width\\\_20

bb\\\_percent\\\_b\\\_20

bb\\\_breakout\\\_up\\\_20

bb\\\_breakout\\\_down\\\_20

atr\\\_14

atr\\\_ratio\\\_14

ma\\\_20\\\_slope

ma\\\_60\\\_slope

ma\\\_120\\\_slope

rsi\\\_14\\\_slope

```



해석:



\- 기술지표를 단순 매수/매도 공식으로 쓰지 않고, 시장 국면과 위험 분위기를 설명하는 feature로 사용했다.

\- 특히 ATR과 Bollinger Band는 고변동 예측과 Risk Guard 목적에 잘 맞는다.



\## 2. 기술지표 추가 고변동 모델 실험



`train\\\_volatility\\\_classifier\\\_with\\\_indicators.py`를 새로 추가했다.



기술지표가 추가된 feature dataset을 사용해 고변동 예측 모델을 다시 학습했다.



기존 baseline 대비 결과:



```text

roc\\\_auc: 0.788064 -> 0.795049

average\\\_precision: 0.599165 -> 0.610102

accuracy: 0.739374 -> 0.746348

precision: 0.518282 -> 0.529561

recall: 0.638955 -> 0.644186

log\\\_loss: 0.525593 -> 0.512464

```



해석:



\- 기술지표 추가가 고변동 예측 성능을 소폭 개선했다.

\- 특히 `atr\\\_ratio\\\_14`가 feature importance 상위권으로 나타났다.

\- 기술지표를 시장 상태를 표현하는 감각기관으로 쓰는 방향이 유효해 보인다.

\- Streamlit 기본 차트보다 TradingView-style candlestick chart가 프로젝트 목적에 더 적합했다.



\## 4. 실시간 가격 기능 추가



Bybit public WebSocket을 사용해 BTCUSDT 실시간 가격을 받아오도록 했다.



사용 endpoint:



```text

wss://stream.bybit.com/v5/public/linear

topic: tickers.BTCUSDT

```



실시간 가격이 들어오면 선택한 timeframe의 마지막 candle을 화면에서 업데이트한다.



WebSocket 실패 시 REST fallback을 사용한다.



```text

https://api.bybit.com/v5/market/tickers?category=linear\\\&symbol=BTCUSDT

```



해석:



\- 컴퓨터가 켜져 있고 Streamlit 앱이 실행 중일 때, 차트가 거래소 차트처럼 실시간으로 움직이는 구조에 가까워졌다.

\- 단, 현재 실시간 가격은 화면 표시용이며 CSV에 자동 저장되는 구조는 아직 아니다.

\- Risk Guard 모델 판단은 여전히 15분봉 feature/model 기준이다.



\## 오늘의 결론



오늘은 프로젝트가 실험 스크립트 단계에서 실제 대시보드 도구 단계로 넘어간 날이다.
