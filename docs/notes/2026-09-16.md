# 2026-09-16 개발일지

## 최신 데이터와 로컬 추론 연결

- 기존 spot 1분봉 원본을 읽고 7월 22일 이후 데이터 80,405개 이상을 Bybit 공개 API에서 증분 수집했다.
- 2021년 7월부터 약 273만 개의 1분봉을 별도 `data/operational/spot`에 저장했다.
- 검증 시점의 전체 원본 timestamp 중복과 역사적 1분 간격 공백은 모두 0개였다.
- 완결된 캔들만 리샘플링하고 미래 target이 없는 최신 15분봉 피처로 기존 고변동·급락 모델을 실행한다.
- 기존 원본·모델·실험 결과는 보존했다. 모델 재학습과 대형 similarity 생성은 하지 않았다.

## 운용 안전성

- 최근 12일 데이터 공백 및 OHLC 이상은 추론을 막는다.
- 실제 피처 종료 시각, 추론 시각, 다음 15분봉 종료 시각을 metadata에 기록한다.
- 오래된 피처의 유효 시간을 재실행으로 연장하지 않는다.
- 수집 프로세스 오류는 `UNKNOWN`, 프로세스 상태 만료는 `STALE`로 표시한다.
- Windows CSV 읽기와 atomic 교체가 겹치는 경우 짧게 재시도한다.
- 원본은 임시 복사본에 새 분봉만 추가한 뒤 교체하고, 리샘플링 파일은 새 완결 봉이 있을 때만 저장한다.
- 수집은 갱신 완료 후 60초 간격, 리스크 카드는 30초 간격으로 확인한다.

기존 모델은 누수 수정 전 학습 결과이므로 `legacy_pre_fix` 경고를 표시한다.
최신 추론 실행 여부와 모델 성능 검증 여부를 구분한다.

## 검증 및 실행

- synthetic 및 기존 회귀 테스트 17개 통과
- 대시보드 통합 실행에서 예외·오류 없이 실제 예측 확률과 정책 상태 표시를 확인
- `start_dashboard.ps1`로 기존 Python 가상환경을 사용해 로컬 프로세스를 실행
- 새 Python용 SciPy는 Windows 정책에 차단돼 사용하지 않았다. 보안 정책은 변경하지 않았다.

다음에는 누수 방지 구조로 기존 모델을 재검증하고, 실시간 similarity query 경로를 분리한다.
