# 2026-09-10 개발일지

## 작업 범위

감사 보고서의 P0 결함 가운데 데이터 재실행 안전성, 예측 최신성, 시장 종류 일치,
공통 리스크 정책과 시계열 검증 누수를 수정했다. 새로운 모델이나 대시보드 기능은 추가하지 않았다.

## 수정 내용

- similarity dataset을 임시 파일에 새로 생성하고 검증 후 atomic replace하도록 변경했다.
- 예측값과 최신성 metadata가 없으면 `UNKNOWN`, 유효 시간이 지났으면 `STALE`로 표시한다.
- 과거 데이터와 현재가 흐름을 Bybit `spot` `BTCUSDT` 기준으로 통일했다.
- 고변동·급락 확률의 공통 정책을 `risk/policy.py`로 분리하고 HIGH drop risk가 `NORMAL`이 되는 경로를 제거했다.
- similarity scaler는 training fold에서만 fit하고 mean, std, feature 순서, fit 기간, source hash를 기록한다.
- 고변동 target threshold는 label이 확정된 training 구간에서만 계산한다.
- train/validation 경계에서 `label_end_time`이 다음 fold를 침범하는 행을 purge한다.
- 전략 threshold는 validation에서 선택하고 final test에는 한 번만 적용한다.
- 대시보드는 `TRADING_AI_DATA_DIR`로 기존 로컬 데이터 폴더를 지정할 수 있다.

## 검증

- 작은 synthetic fixture 기반 테스트 12개 통과
- CSV 재실행, `UNKNOWN`/`STALE`, spot 일치, 공통 risk policy 회귀 테스트 통과
- scaler·target threshold 미래 정보 누수, historical label 불변성, boundary purge,
  irregular timestamp, validation/test threshold 격리 테스트 통과
- 관련 Python syntax/import 수준 검사 통과

전체 데이터셋 생성, 전체 모델 재학습, 전체 백테스트는 실행하지 않았다.

기존 로컬 1분봉은 2026-07-22, feature와 prediction은 2026-07-06에서 멈춰 있다.
