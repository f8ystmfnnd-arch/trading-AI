# 로컬 운용

`start_dashboard.ps1`은 기존 Python 가상환경으로 수집 프로세스와 대시보드를 실행한다.
Python 경로가 다르면 `-PythonPath`로 지정한다. 기본 접속 주소는 `http://localhost:8504`이다.

수집 프로세스는 기존 spot 1분봉을 읽고 누락된 최신 데이터만 Bybit 공개 API에서 받아
`data/operational/spot`에 새 운용 산출물을 저장한다. 기존 원본과 모델은 변경하지 않는다.
매 갱신 완료 후 60초마다 다시 수집하며, 대시보드 리스크 카드는 30초마다 최신 상태를 확인한다.

- 리샘플은 모든 1분봉이 존재하고 종료 시각이 지난 캔들만 사용한다.
- 최근 12일의 누락된 1분봉과 OHLC 이상은 예측 생성을 막는다.
- 운용용 피처는 미래 target을 포함하지 않으며 마지막 완결된 15분봉까지 생성한다.
- `feature_asof`는 캔들 종료 시각, `predicted_at`은 실제 모델 실행 시각이다.
- `valid_until`은 다음 15분봉 종료 시각으로 고정한다. 재실행으로 오래된 피처의 유효 시간을 연장하지 않는다.
- 갱신 검증 실패는 `UNKNOWN`, 프로세스 상태가 3분 넘게 갱신되지 않으면 `STALE`로 표시한다.

기존 모델은 수정 전 학습 결과이므로 `legacy_pre_fix`로 명시한다.
최신 예측을 실행할 수 있다는 사실은 모델의 성능을 재검증했다는 뜻이 아니다.
기존 similarity 대용량 산출물과 학습/백테스트 결과는 이 운용 갱신에서 다시 생성하지 않는다.

상태는 `data/operational/spot/operational_status.json`, 실행 로그는 `work/live`에서 확인한다.
학습, 주문 전송, 외부 배포는 하지 않는다.
